Objetos de aprendizagem do projeto de extensão (Mackenzie, 2º sem. 2026).

| Data | Entrega |
|---|---|
| 30/10 | Entrega parcial: escopo e conteúdo pretendido (formulário 1) |

## Estrutura

- `versao1/*.md`: fonte de cada objeto (texto, roteiro do vídeo, caso prático, desafio, quiz, checklist, teste final)
- `versao1/pdf/`: PDFs prontos para o formulário
- `versao1/gerar-pdfs.sh`: regenera os PDFs depois de editar os `.md` (requer `pandoc` e `xelatex`)
- `versao1/original/`: primeira versão (06/10)
- `transcricao_reuniao_entregaveis.txt`: transcrição da reunião de 02/10 sobre os entregáveis
