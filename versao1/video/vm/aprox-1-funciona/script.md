# Como o pagamento por aproximação funciona

## nfc {hold=0.5 chapter="A tecnologia"}
[#encosta] Esse pagamento usa uma tecnologia chamada {NFC|éne éfe cê}. [#perto] Ela só funciona a poucos centímetros.

## codigo {hold=0.5 chapter="Um código por compra"}
[#gera] Cada compra gera um código diferente. [#copia] Por isso, copiar os dados não adianta. [#abecs] Em 2020, a Abecs disse que não viu problema significativo de segurança.

## limite {hold=0.8 chapter="O ponto fraco"}
[#fraco] O ponto fraco é outro. [#ate] Compras de até cerca de {R$ 200|duzentos reais} passam sem senha. [#mao] Se o cartão cair na mão errada, [#dinheiro] ele funciona quase como dinheiro.
