Para a segunda etapa do projeto de extensão, os entregáveis esperados para cada temática são:

  * **Vídeo curto de 5 minutos:** Vídeo autoral intitulado "Como funciona o golpe", onde todos os integrantes do grupo devem aparecer na câmera.
  * **Texto:** Exemplo: "5 golpes de Pix que você precisa conhecer".
  * **Caso prático:** Exemplo: "Você recebe esta mensagem no WhatsApp...".
  * **Desafio:** Atividade para identificar os sinais de fraude.
  * **Quiz:** Questionário contendo 5 questões.
  * **Checklist:** Exemplo: "Antes de fazer um Pix...".
  * **Infográfico para download**.
  * **Teste final da linha de desenvolvimento**.
  * **Badge:** Gerado automaticamente pela plataforma após a conclusão.
  * **Certificado:** Gerado automaticamente pela plataforma.

**Informações importantes:**

  * **Prazo de finalização:** 12/11/2026.
  * **Identificação dos grupos:** Deve ser preenchida na planilha compartilhada na nuvem (coluna C), com no máximo 3 alunos por temática.
